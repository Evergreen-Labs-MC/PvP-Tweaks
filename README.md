# Minecraft PvP just got better!

[![Available on Modrinth](https://img.shields.io/badge/Available_on-Modrinth-00AF5C?style=for-the-badge&logo=modrinth&logoColor=white)](https://modrinth.com/resourcepack/pvptweaks+/versions)

## Description
This resource pack bridges the gap between Minecraft's beautiful default aesthetic and high-performance competitive gameplay. Designed specifically for PvP enthusiasts who love the vanilla texture style, this pack introduces clean, subtle Quality-of-Life (QOL) enhancements. Every tweak is engineered to maximize screen real estate, improve situational awareness, and deliver buttery-smooth performance without sacrificing the game's classic charm. 

By strategically lowering first-person shield profiles, shortening weapon models, and adding clean, translucent container GUIs, you get a significant competitive advantage without changing how the actual world looks. Combat particles, item sprites, and ranged weapon pull animations are all subtly cleaned up to ensure absolute visual clarity during fast-paced arena fights while keeping the environment 100% true to Minecraft's iconic look.

## Installation
1. **Download:** Grab the latest release `.zip` file from the **Releases** tab on GitHub (or via Modrinth).
2. **Open Folder:** Launch Minecraft, go to **Options** > **Resource Packs**, and click **Open Pack Folder**.
3. **Move File:** Drag and drop the downloaded `.zip` file into the folder that opened.
4. **Activate:** Back in Minecraft, hover over the pack, click the arrow icon to move it to the **Selected** list (ensure it sits at the very top), and click **Done**.
